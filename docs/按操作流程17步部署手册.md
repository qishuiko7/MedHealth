# 集群侧（步骤 1~7）

## 步骤 1：安装 VMware Workstation 【Windows，10 min】

1. 双击 `D:\bigdata-pkg\VMware-workstation-full-17.x.exe`。
2. 向导：Next → 勾 *I accept the terms* → Next → **安装位置改 `D:\soft\vmware\`**（点 Change 修改）→ 选项页：勾 *Enhanced Keyboard Driver*（可选）、勾桌面/开始菜单快捷方式 → Install → Finish。
3. 首次启动弹许可界面：选 **"Use VMware Workstation 17 for Personal Use"**（个人免费）→ Continue → Finish → 输入管理员权限确认。
4. **配置 NAT 网段（关键，漏做后面全断）**：菜单 `编辑(Edit) → 虚拟网络编辑器(Virtual Network Editor)` → 右下角点 **"更改设置"(Change Settings)** 获取管理员权限 → 选中列表里的 **VMnet8 (NAT)**：
   - 子网 IP(Subnet IP)：`192.168.10.0`，子网掩码 `255.255.255.0`
   - **取消勾选** "使用本地 DHCP 服务将 IP 地址分配给虚拟机"（我们全静态）
   - 点 **NAT 设置**：网关 IP 填 `192.168.10.2` → 确定 → 应用。
5. 检查宿主机虚拟网卡：`Win+R` → `ncpa.cpl` → 找到 *VMware Network Adapter VMnet8* → 右键属性 → IPv4 应为 `192.168.10.1/255.255.255.0`（不是就手动改成这个，网关可空）。

**✅ 验收**：VMware 正常打开；`cmd` 执行 `ipconfig` 能看到 VMnet8 的 IPv4 = 192.168.10.1。

## 步骤 2：安装 FinalShell 【Windows，5 min】

1. 双击 `finalshell_install.exe` → 安装位置改 `D:\soft\finalshell\` → Install → 完成。
2. 打开 FinalShell：左上角**文件夹+号图标** → 新建连接 → **SSH 连接**：
   - 名称：`hadoop01-root`；主机：`192.168.10.101`；端口：`22`
   - 用户名/密码：等步骤 3 装完 CentOS 再填（root / 123456）
   - 先保存（此时连不上是正常的，VM 还没装）。

**✅ 验收**：FinalShell 打开无报错，左侧出现 `hadoop01-root` 连接项。

## 步骤 3：VMware 中部署 CentOS 【VM，30~40 min】

### 3.1 创建虚拟机

1. VMware 主页 → **创建新的虚拟机** → 选 **自定义(高级)** → 下一步。
2. 硬件兼容性：默认 Workstation 17.x → 下一步。
3. 安装客户机操作系统：选 **"稍后安装操作系统"**（不要选第一个！否则会装成简易版）→ 下一步。
4. 客户机操作系统：**Linux** → 版本 **CentOS 7 64位** → 下一步。
5. 名称：`hadoop01`；位置：**`D:\vm\hadoop01`**（手动新建此目录）→ 下一步。
6. 处理器：处理器数量 `2`、每个内核 `2`（共 4 核）→ 下一步。内存：**8192 MB**（宿主只有 8GB 就选 4096）→ 下一步。
7. 网络类型：**使用网络地址转换(NAT)** → 下一步。SCSI 控制器：LSI Logic → 下一步。磁盘类型：SCSI → 下一步。
8. 磁盘：**创建新虚拟磁盘** → 大小 **60 GB** → 勾选 **"将虚拟磁盘存储为单个文件"**（性能更好）→ 下一步 → 磁盘文件名默认 → 下一步。
9. 点 **"自定义硬件"** → 左侧选 *CD/DVD (IDE)* → 右侧连接选 **"使用 ISO 映像文件"** → 浏览选中你下载好的 CentOS-7-x86_64-DVD-2009.iso（本手册 0.3 节第 3 项，**未随包分发，需自行下载**）→ 关闭 → 完成。

### 3.2 安装系统

1. 左侧库选中 hadoop01 → **开启此虚拟机** → 启动菜单选第一项 **Install CentOS 7** 回车。
2. 语言：选 **English (United States)** 或中文均可（推荐 English，减少终端/locale 乱码）→ Continue。
3. **INSTALLATION SUMMARY** 页逐项设置：
   - **DATE & TIME**：地图点上海，或 Region=Asia / City=Shanghai → Done。
   - **SOFTWARE SELECTION**：选 **GNOME Desktop**（带图形界面，适合初学；右侧附加组件默认）→ Done。（熟练者可换 Minimal Install，但后续截图操作没有 GUI。）
   - **INSTALLATION DESTINATION**：选中 60GB 磁盘（图标变黑）→ Storage Configuration 选 **Automatically configure partitioning** → Done。
   - **NETWORK & HOST NAME**：右上角 ens33 开关拨 **ON**；左下 Host name 填 **`hadoop01`** → Apply → Done。
   - **Begin Installation**。
4. 安装进行中同时设置：点 **ROOT PASSWORD** → 输入 `123456` → （弱密码警告）连点两次 Done。点 **USER CREATION** → Full name/Username 都填 `hadoop`，密码 `hadoop123`，**勾选 "Make this user administrator"** → Done。
5. 约 10~20 分钟装完 → **Reboot** → 重启后接受许可证（License Information → 勾选 I accept → Done → Finish Configuration）。

### 3.3 配置静态 IP（root 登录图形界面 → Applications → Terminal）

```bash
vi /etc/sysconfig/network-scripts/ifcfg-ens33
```

修改/确保以下行（UUID、NAME、DEVICE 原有行不要动）：

```ini
BOOTPROTO=static        # 原 dhcp 改 static
ONBOOT=yes              # 原 no 改 yes
IPADDR=192.168.10.101
NETMASK=255.255.255.0
GATEWAY=192.168.10.2
DNS1=192.168.10.2
```

保存退出（`Esc` → 输入 `:wq`）后：

```bash
systemctl restart network
ip addr                 # ens33 应显示 192.168.10.101
ping -c 3 192.168.10.2  # 通网关
ping -c 3 www.baidu.com # 通外网（DNS 正常）
```

**Windows 侧配 hosts**：右键开始菜单 → 搜索"记事本" → 右键**以管理员身份运行** → 打开 `C:\Windows\System32\drivers\etc\hosts` → 末尾追加一行：


```
192.168.10.101  hadoop01
```

保存。然后 `cmd` 执行 `ping hadoop01` 应通。

**✅ 验收**：FinalShell 里 `hadoop01-root` 连接（用户 root/123456）能登录，弹出终端。

### 3.4 系统初始化（FinalShell 里逐块粘贴执行）

```bash
# ① 关防火墙 + SELinux
systemctl stop firewalld && systemctl disable firewalld
sed -i 's/SELINUX=enforcing/SELINUX=disabled/' /etc/selinux/config
setenforce 0

# ② 时间同步（chronyd 默认已装）
systemctl enable --now chronyd && chronyc sources | head -5

# ③ 确认 hadoop 用户（3.2 已建；若 Minimal 安装未建则执行下面两行）
id hadoop || (useradd -m hadoop && echo "hadoop:hadoop123" | chpasswd)
echo "hadoop ALL=(ALL) NOPASSWD:ALL" >> /etc/sudoers   # 免密 sudo，课程环境

# ④ 目录规划
mkdir -p /opt/software /opt/module /data
chown -R hadoop:hadoop /opt/module /data
chown -R root:root /opt/software   # 安装包放这里，上传时用 root 权限即可
```

### 3.5 免密登录（切到 hadoop 用户操作）

```bash
su - hadoop
ssh-keygen -t rsa -P '' -f ~/.ssh/id_rsa          # 三连回车
cat ~/.ssh/id_rsa.pub >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
ssh hadoop01 date                                  # 首次要输 yes，之后免密直接出日期
```

**✅ 验收**：`ssh hadoop01 date` 不输密码直接返回时间。

### 4.3 安装 MySQL 8（VM 内，作 Hive 元数据库）

> CentOS 7 已停维，**先修 yum 源再装**，否则一堆 404。

```bash
# ① 修复 CentOS 7 EOL 源（mirrorlist 已死，切 vault）
sudo sed -i -e 's|^mirrorlist=|#mirrorlist=|g' \
            -e 's|^#baseurl=http://mirror.centos.org|baseurl=http://vault.centos.org|g' \
            /etc/yum.repos.d/CentOS-*.repo
sudo yum clean all && sudo yum makecache

# ② 装 wget 并配置 MySQL 官方 yum 源
sudo yum install -y wget
sudo wget https://dev.mysql.com/get/mysql80-community-release-el7-11.noarch.rpm
sudo rpm -ivh mysql80-community-release-el7-11.noarch.rpm

# ③ 导入 2023 版 GPG key（2023 后的 MySQL rpm 必需，否则报 GPG 校验失败）
sudo rpm --import https://repo.mysql.com/RPM-GPG-KEY-mysql-2023

# ④ 安装并启动
sudo yum install -y mysql-community-server
sudo systemctl start mysqld && sudo systemctl enable mysqld

# ⑤ 取临时密码并登录改密
sudo grep 'temporary password' /var/log/mysqld.log
mysql -uroot -p     # 粘贴上面的临时密码
```

在 `mysql>` 提示符下执行：

```sql
ALTER USER 'root'@'localhost' IDENTIFIED BY 'Root_123456';   -- 先改成合规强密码
SET GLOBAL validate_password.policy = 0;                     -- 课程环境降低密码策略
SET GLOBAL validate_password.length = 4;
ALTER USER 'root'@'localhost' IDENTIFIED BY '123456';        -- 再改成统一口径
CREATE DATABASE hive_meta DEFAULT CHARSET utf8;              -- 注意：库名 hive_meta，与 env.sh 一致
CREATE USER 'hive'@'%' IDENTIFIED BY 'hive123456';
GRANT ALL PRIVILEGES ON hive_meta.* TO 'hive'@'%';
FLUSH PRIVILEGES;
EXIT;
```

**✅ 验收**：`mysql -uhive -phive123456 -e "show databases;"` 能看到 `hive_meta`。

## 步骤 5：Linux 部署 Hadoop、Hive 【VM，40 min】

```bash
cd /opt/software/deploy
sudo bash 03_install_hadoop.sh    # 解压/软链 → core|hdfs|yarn|mapred-site.xml → workers → 格式化 NameNode → 启动 HDFS+YARN
sudo bash 04_install_hive.sh      # 解压 → hive-site.xml(指向 jdbc:mysql://hadoop01:3306/hive_meta) → 放 JDBC 驱动 → 修 guava 冲突 → schematool 初始化 → 启动 metastore + hiveserver2
```

脚本内置的关键配置（出问题时对照）：

- `fs.defaultFS = hdfs://hadoop01:8020`；NameNode Web UI 端口 **9870**；YARN Web UI **8088**
- 数据目录 `/data/hdfs/name`、`/data/hdfs/data`
- Hive 元库：`jdbc:mysql://hadoop01:3306/hive_meta`，账号 `hive/hive123456`
- Hive metastore thrift 端口 **9083**，HiveServer2 **10000**

**两个关键问题（脚本已处理，手动安装时需注意）**：

1. **NameNode 只格式化一次**。重装不要重复 `hdfs namenode -format`，否则 DataNode clusterID 不一致起不来（恢复办法见《集群部署文档.md》§八.1）。
2. Hive 3.1.3 自带 guava-19 与 Hadoop 3.3.6 的 guava-27 冲突：把 `$HADOOP_HOME/share/hadoop/hdfs/lib/guava-27.0-jre.jar` 拷贝覆盖 `$HIVE_HOME/lib/guava-19.0.jar`（04 脚本已做）。

**✅ 验收**：

```bash
jps   # hadoop 用户下，应出现：NameNode、DataNode、SecondaryNameNode、ResourceManager、NodeManager、metastore?、RunJar×2
```

Windows 浏览器打开 `http://hadoop01:9870`（HDFS Overview，Live Nodes=1）和 `http://hadoop01:8088`（YARN）。

```bash
beeline -u "jdbc:hive2://hadoop01:10000" -n hadoop -e "show databases;"   # 返回 default
```

## 步骤 11：数据保存到 Linux 的 HDFS 【Windows→VM，10 min】

> 目标路径由 `01_ods_ddl.sql` 的 LOCATION 决定，**严格为 `/med_health/ods/<表名>/`**，表名与 CSV 文件名一一对应（9 张表：ods_admission / ods_department / ods_disease / ods_doctor / ods_drug / ods_patient / ods_prescription / ods_registration / ods_visit）。

**方式 A（推荐）：Python hdfs 客户端**。新建 `<项目根>\code\upload_hdfs.py`：

```python
# -*- coding: utf-8 -*-
"""把 code/output/ods/ 的 9 张 ODS CSV 上传到 HDFS /med_health/ods/<表名>/"""
import os, glob
from hdfs import InsecureClient

client = InsecureClient("http://hadoop01:9870", user="hadoop")
ods_dir = os.path.join(os.path.dirname(os.path.abspath(__file__)), "output", "ods")
for csv in glob.glob(os.path.join(ods_dir, "ods_*.csv")):
    table = os.path.splitext(os.path.basename(csv))[0]          # ods_registration
    target = f"/med_health/ods/{table}/{table}.csv"
    client.makedirs(f"/med_health/ods/{table}", permission=755)
    client.upload(target, csv, overwrite=True)
    print("uploaded ->", target)
```


```powershell
conda activate med_health
cd <项目根>\code
python upload_hdfs.py
```

hdfs dfs -ls /med_health/ods

## C. 本路线专属坑速查（全部为实测教训）

1. **CentOS 7 yum 全部 404** → EOL 源修复（步骤 4.3 ①），不做后面什么都装不了。
2. **MySQL rpm 报 GPG key 失败** → `rpm --import https://repo.mysql.com/RPM-GPG-KEY-mysql-2023`。
3. **NameNode 只格式化一次**；DataNode 起不来先查 clusterID。
4. **Hive 起不来** → guava 冲突 + mysql-connector-j 是否在 `$HIVE_HOME/lib`。
5. **VM 连不上 Windows 的 3306** → 检查三件事：MySQL 是否建了 `'root'@'%'`、Windows 防火墙 3306 规则、VMnet8 是否 192.168.10.1。
6. **ODS 查出来 0 行** → 步骤 11 上传路径与 `01_ods_ddl.sql` LOCATION 不一致（必须 `/med_health/ods/<表名>`，区分大小写）。
