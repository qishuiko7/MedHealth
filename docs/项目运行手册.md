# 医疗健康数据平台与疾病统计分析 —— 项目运行手册

> 课程：《大数据平台架构与应用开发课程设计》
> 本手册面向**两种运行方式**：
> 1. **Windows 单机复现（推荐用于答辩演示）**：无需集群，一条命令跑通「数据生成 → 数仓分层 → 指标计算 → 落 MySQL → 启动 Flask 大屏」全链路。
> 2. **Linux 集群方式**：在部署好的 Hadoop/Hive/Spark/Kafka 集群上运行 PySpark 作业与实时链路。
>
> 说明：文中脚本名称为**占位示例**，实际入口**与主工程一致，见 `code/` 目录**。主工程目录约定：
> `code/data_generator/`（数据生成）、`code/realtime/`（实时爬虫与流处理）、`code/warehouse/`（ODS/DWD/DWS/ADS 分层 SQL）、
> `code/local_engine/`（单机计算引擎）、`code/web/`（Flask 大屏）、`code/realtime/`（实时链路）。

## 一、环境准备（Windows 单机）

### 1.1 软件要求

| 软件 | 版本 | 说明 |
|---|---|---|
| Anaconda / Python | 3.9 或 3.10 | 计算与可视化运行环境 |
| MySQL | 8.0（或 5.7，本地 3306） | 业务库 `med_health` |
| PyCharm | 2023+ | 开发调试（可选） |
| JDK | 8 或 11 | 仅当本地运行 PySpark 时需要 |
| 浏览器 | Chrome / Edge | 访问 Flask 大屏 |

### 1.2 创建并激活环境

```powershell
conda create -n med_health python=3.10 -y
conda activate med_health

pip install -i https://pypi.tuna.tsinghua.edu.cn/simple ^
    pandas numpy pyarrow openpyxl ^
    pymysql sqlalchemy ^
    flask flask-cors ^
    pyspark==3.5.1 ^
    kafka-python ^
    requests beautifulsoup4 lxml
```

### 1.3 准备本地 MySQL

```sql
-- 在本地 MySQL（127.0.0.1:3306）执行
CREATE DATABASE IF NOT EXISTS med_health DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

主工程 `code/data_generator/config.py` 中的连接信息默认：

```python
MYSQL = {"host": "127.0.0.1", "port": 3306, "user": "root",
         "password": "", "database": "med_health", "charset": "utf8mb4"}
```

> 如你的 MySQL root 有密码，请同步修改上述 `password`（或使用环境变量覆盖，见 §1.5）。

### 1.4 目录自检

进入项目后确认关键目录存在：

```powershell
cd <项目根>/code
dir
# 预期包含：data_generator  warehouse  local_engine  web  realtime  output  deploy  docs
```

### 1.5 可配置项（环境变量，可选）

| 变量 | 默认 | 说明 |
|---|---|---|
| `MYSQL_HOST` | 127.0.0.1 | 业务库地址 |
| `MYSQL_PORT` | 3306 | 业务库端口 |
| `MYSQL_USER` / `MYSQL_PWD` | root / 空 | 账号密码 |
| `MYSQL_DB` | med_health | 库名 |
| `WEB_HOST` / `WEB_PORT` | 127.0.0.1 / 5000 | Flask 监听 |
| `KAFKA_BOOTSTRAP` | hadoop01:9092 | 实时链路 Broker |

## 二、一键跑通（Windows 单机链路）

> 目标：数据生成 → 数仓分层 → 指标计算 → 落 MySQL → 启动 Flask 大屏。

### 2.1 方式 A：一键脚本（推荐）

```powershell
conda activate med_health
cd <项目根>/code

python run_all.py
```

> `run_all.py` 为**占位名**，实际入口与主工程一致（见 `code/` 目录）。
> 若主工程未提供总控脚本，请按 §2.2 分步执行。

### 2.2 方式 B：分步执行（便于排查）

```powershell
conda activate med_health
cd <项目根>/code

# ① 生成 10 万级模拟数据（挂号/就诊/处方等）
python data_generator/gen_source_data.py      # 离线业务明细，见 code/data_generator/

# ②（可选）爬取中国疾控中心公开疫情公报
python realtime/crawler.py --pages 3 --dump output/crawl.json   # 见 code/realtime/

# ③ ODS → DWD → DWS → ADS 数仓分层（本地引擎 + warehouse 下 SQL）
python local_engine/etl_local.py              # 见 code/local_engine/

# ④ 指标计算并落本地 MySQL（med_health 库）
python -m local_engine.<落库入口>            # 与主工程一致，见 code/local_engine/

# ⑤ 启动 Flask 可视化大屏
python web/app.py                            # 与主工程一致，见 code/web/
```

浏览器访问：**http://127.0.0.1:5000**

### 2.3 产物位置

| 产物 | 路径 |
|---|---|
| ODS 贴源数据 | `code/output/ods/` |
| DWD 明细 | `code/output/dwd/` |
| DWS 汇总 | `code/output/dws/` |
| ADS 应用指标 | `code/output/ads/` |
| 图表图片 | `code/images/` |
| MySQL 业务表 | `med_health` 库（各层表名与主工程一致） |

### 2.4 验收检查清单

- [ ] `code/output/ods|dwd|dws|ads` 下均有数据文件。
- [ ] MySQL `med_health` 库中可 `SELECT` 到 ADS 指标表。
- [ ] 浏览器打开 `http://127.0.0.1:5000`，ECharts 大屏正常渲染（疾病排行、科室就诊量、趋势图等）。
- [ ] 平台登录账号（见 `config.py` 的 `USERS`）：`admin/admin123`、`doctor/doctor123`、`viewer/viewer123`。

## 三、实时链路运行（Windows 生产 + Linux/本地消费，可选）

实时链路用于「爬虫实时采集 → Kafka → Spark Streaming → MySQL → 前端刷新」。
爬虫来源为**中国疾控中心官网公开疫情公报**（`code/realtime/crawler.py`）。

### 3.1 启动顺序

```powershell
conda activate med_health
cd <项目根>/code

# 1)（Linux 集群）确保 Kafka 已启动且三个主题存在：
#    med_registration / med_visit / med_prescription

# 2) 启动实时爬虫（CDC 公开公报 -> Kafka）
python realtime/crawler.py --pages 3 --rate 15
#    无 Kafka 时降级：python realtime/crawler.py --local（写 stream_events.jsonl）
#    旧版模拟生产者仍保留：python realtime/producer.py（爬虫不可达时备选）

# 3) 启动 Spark Streaming 消费处理（本地模式即可演示）
python realtime/local_stream.py --window 10          # 单机等价版（无需 Spark 集群）
#    集群版：spark-submit --master local[2] realtime/spark_streaming_job.py --ck-clean

# 4) Flask 大屏每 N 秒轮询 /api/realtime 刷新实时指标
python web/app.py
```

### 3.2 本地模式（无需集群）

若只想在 Windows 单机演示实时效果，用爬虫 `--local` 写 `stream_events.jsonl`，再由 `local_stream.py` 按同口径窗口聚合并写 MySQL：

```powershell
# 终端 1：爬虫写本地事件流
python realtime/crawler.py --local --pages 3 --rate 12
# 终端 2：本地窗口聚合写 MySQL（无需 Kafka / Spark 集群）
python realtime/local_stream.py --window 10
```

## 四、Linux 集群方式运行 PySpark 作业

> 前置：已完成《集群部署文档》1~6 步，`07_verify_all.sh` 全部 PASS。

### 4.1 提交离线批处理作业

```bash
source /etc/profile.d/bigdata_env.sh

# ① 本地模式（单机调试最快）
spark-submit --master local[*] \
  --name med_offline_local \
  code/warehouse/<离线作业>.py

# ② Spark Standalone 集群模式
spark-submit \
  --master spark://hadoop01:7077 \
  --executor-memory 2g --total-executor-cores 2 \
  --name med_offline \
  code/warehouse/<离线作业>.py

# ③ Spark on YARN 模式
spark-submit \
  --master yarn --deploy-mode client \
  --executor-memory 2g --num-executors 2 \
  code/warehouse/<离线作业>.py
```

> 作业脚本名与主工程 `code/warehouse/`、`code/local_engine/` 一致，见 `code/` 目录。

### 4.2 读取 Hive 数仓（Spark SQL）

Spark 已通过软链 `$SPARK_HOME/conf/hive-site.xml` 接入 Hive 元数据：

```bash
spark-sql --master local[2] -e "USE med_health; SHOW TABLES; SELECT * FROM ads_disease_distribution LIMIT 10;"
```

或在 PySpark 中：

```python
from pyspark.sql import SparkSession
spark = SparkSession.builder.appName("med_hive").enableHiveSupport().getOrCreate()
spark.sql("USE med_health")
spark.sql("SELECT * FROM ads_disease_distribution LIMIT 10").show()
```

### 4.3 提交实时 Streaming 作业（Kafka 集成）

```bash
# 方式A：联网自动拉取 Kafka 连接器
spark-submit \
  --master spark://hadoop01:7077 \
  --packages org.apache.spark:spark-sql-kafka-0-10_2.12:3.5.1 \
  --name med_realtime \
  code/realtime/<Streaming入口>.py

# 方式B：已离线预置 jar（见部署脚本 06），直接提交
spark-submit \
  --master spark://hadoop01:7077 \
  --jars $SPARK_HOME/jars/spark-sql-kafka-0-10_2.12-3.5.1.jar \
  --name med_realtime \
  code/realtime/<Streaming入口>.py
```

### 4.4 结果落库到 MySQL

- **落到 Linux 端 MySQL**：JDBC URL 用 `jdbc:mysql://hadoop01:3306/med_health`。
- **落到 Windows 端 MySQL**（步骤 16）：JDBC URL 用 `jdbc:mysql://<Windows主机IP>:3306/med_health`，
  并确保 Windows 防火墙放行 3306、MySQL 有远端授权账号：
  ```sql
  CREATE USER 'spark'@'%' IDENTIFIED BY 'spark123456';
  GRANT ALL PRIVILEGES ON med_health.* TO 'spark'@'%';
  FLUSH PRIVILEGES;
  ```

## 五、常见运行问题

| 现象 | 排查 |
|---|---|
| `ModuleNotFoundError` | 未激活 `med_health` 环境，`conda activate med_health` |
| MySQL 连接被拒 `1045` | `config.py` 的账号密码与本地 MySQL 不一致 |
| `pyspark` 启动报 `JAVA_HOME` | 设置 `set JAVA_HOME=<jdk路径>` 后重开终端 |
| Windows 本地写 HDFS 报 `winutils` | 仅本地文件系统可先跑通；连集群用 hdfs 客户端或把数据放集群端处理 |
| Kafka 连不上 `hadoop01:9092` | 确认集群 Kafka 已启动、`/etc/hosts` 或 DNS 能解析 `hadoop01`；Windows 的 hosts 也可加 `192.168.10.101 hadoop01` |
| Spark Streaming 无输出 | 检查三个主题是否有数据、`startingOffsets`、水印/窗口配置 |
| Flask 端口 5000 被占用 | 改 `WEB_PORT` 或释放端口（Windows：`netstat -ano \| findstr 5000`） |
| 前端图表空白 | 打开浏览器控制台看 AJAX 请求 `/api/*` 是否 200、是否跨域（`flask-cors`） |
